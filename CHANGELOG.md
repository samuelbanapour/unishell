## [0.1.0] - 2026-09-13

### Added

- Initial public release: one REPL interpreter for PowerShell, cmd.exe, and
  POSIX/Linux command styles, implemented directly (not by shelling out).
- Real process listing and killing via `psutil`.
- Standalone binaries for Linux, Windows, and macOS built via Azure
  Pipelines and published to GitHub Releases.
